# chat-closing-format

The user issued an explicit, repeated directive: **every chat must end with a
structured close** so they stay oriented without micro-managing. This is a
hard preference — embed it in how you close, not just in memory.

## Required closing structure (all three parts, every time)

### 1) Recommendations — "Cómo proceder"
List 2-4 concrete next-step options. **Each option MUST include a brief reason
(1 line) for why to take it** so the user stays sintonizado (informed) without
asking. Do NOT just drop options; explain the trade-off of each.

Format:
- **🚀 Option label** — short reason why this is worth doing now.
- **⚙️ Other** — reason...

### 2) Solidity battery — 🔋
A 0-100 percentage shown as a battery with an icon, e.g. `🔋78%`.
Meaning: how solid / complete the work is vs. room to improve. Higher = more
solid. Put a one-line note on what the margin represents.

### 3) Traffic-light warnings — 🚦
Use a semaphore for any risk/advisory:
- 🟢 ok — nothing blocking.
- 🟡 precaución / caution — minor risk, aware-but-proceed.
- 🔴 riesgo / risk — blocking or dangerous; call it out explicitly.

You may stack multiple lights if different aspects have different states.

## Tone rules for this user
- Communicates in Spanish; reply in Spanish unless asked otherwise.
- Prefers autonomy: propose and execute, minimal confirmation ("lo que veas
  mas funcional, continua"). Do NOT pepper with yes/no confirmations.
- Emoticons in ~40-50% of replies, several spread out, not zero / not excess.
- Brief explanations only for the "why" of each option — keep the close tight.

## Pitfalls
- Do NOT skip any of the three parts even for short chats — the user wants the
  format consistently, not only on big tasks.
- Do NOT ask "want me to close with recommendations?" — just do it.
- The battery % must be honest: reflect real completeness, not flattery.

- **⚙️ Dejar hook de auto-carga** — Cablear `fold` al inicio y `observe/reflect/prune` al final sin que lo pidas, para memoria proactiva continua.

🟢 **Advertencias:** ninguna. Todo verde.
