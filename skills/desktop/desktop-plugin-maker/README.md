# Desktop Plugin Maker Skill

Reusable guidance for building, testing, migrating, and open-sourcing Hermes Desktop disk plugins.

## Contents

- `SKILL.md` — the procedural skill
- `references/position-surface-contracts.md` — verified contribution-area contracts and placement matrix

## Install

Copy this directory to your Hermes skills directory:

```text
<HERMES_HOME>/skills/desktop-plugin-maker/
```

The skill is then available to Hermes agents as `desktop-plugin-maker`.

## Scope

The skill covers native Desktop surfaces, route/sidebar composition, plugin backends, security boundaries, generic local-HTML presentation, open-source export hygiene, ID/folder migrations, and verification.
